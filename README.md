# ২য় রোভার স্কাউট লিডার ওয়ার্কশপ ২০২৬ — কিউআর স্ক্যান পেজ

সনদের কিউআর কোড স্ক্যান করলে এই পেজটিই খুলবে। পেজে থাকছে প্রোগ্রামের তথ্য,
ওয়ার্কশপ স্টাফের তালিকা, সময়সূচি, দুটি রেফারেন্স চার্ট এবং যে সনদ থেকে স্ক্যান
করা হয়েছে সেই অংশগ্রহণকারীর তথ্য। সব লেখা ইংরেজিতে, সনদের সঙ্গে মিলিয়ে।

## GitHub Pages-এ রাখার ধাপ

1. github.com-এ `gopalganjrover` অ্যাকাউন্টে লগইন করুন।
2. উপরে ডানদিকে **+ → New repository**। নাম দিন **`rslw26`**, **Public** রাখুন,
   **Create repository**।
3. **Add file → Upload files** → এই ফোল্ডারের **তিনটি** ফাইল একসঙ্গে টেনে ছাড়ুন —
   `index.html`, `rsl_chart_lifecycle.png`, `rsl_chart_youth.png` → **Commit changes**।
   (চার্ট দুটি না দিলে পেজের ‘Reference Charts’ অংশে ছবি দেখাবে না।)
4. **Settings → Pages** → Source-এ **Deploy from a branch**, Branch **main**,
   ফোল্ডার **/(root)** → **Save**।
5. এক-দুই মিনিট পর ঠিকানাটি সচল হবে:

   ```
   https://gopalganjrover.github.io/rslw26/
   ```

## যাচাই

ঠিকানার শেষে `#C=001` যোগ করে দেখুন —
`https://gopalganjrover.github.io/rslw26/#C=001` — ‘Participant Details’ ঘরে
নমুনা হিসেবে ০০১ নম্বর সনদের তথ্য দেখাবে। সনদের কিউআর স্ক্যান করলেও একই পেজ খুলবে।

## তথ্য হালনাগাদ

`index.html`-এর নিচের `<script>` অংশে চারটি তালিকা আছে — `PROGRAMME`, `STAFF`,
`SCHEDULE` এবং `PARTICIPANTS`। `………` চিহ্নিত ঘরগুলিতে তথ্য বসালেই পেজ হালনাগাদ
হবে। অংশগ্রহণকারীর তালিকা রেজিস্ট্রেশন ফরমের শিট থেকে স্বয়ংক্রিয়ভাবে বসিয়ে
দেওয়া যাবে।

পি.আর.এস ওয়ার্কশপের পেজটি আলাদা রিপোজিটরিতে (`prs26`) থাকবে; দুটি প্রোগ্রামের
সনদ দুটি আলাদা ঠিকানায় যাচাই হবে।
